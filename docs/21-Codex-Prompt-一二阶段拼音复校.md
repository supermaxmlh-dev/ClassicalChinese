# Codex Prompt · 第一、二阶段（001–095）拼音复校（第二轮）

> 前两轮拼音校正主要修了 食/说=悦/知=智/召=shào/夫=fú/朝=zhāo/属=zhǔ 等，但**遗漏了一类破读**：量词与动词的特殊读音（乘=shèng、度=duó、遗=wèi、强=qiǎng…）。本轮对 001–095 做**复校**，重点补这些漏网类型，并全面再扫一遍。
>
> 机制同 `docs/13`/`14`/`19`：在 `content/raw/{id}-*.txt` 给读错的那一处加手工 `<ruby>字<rp>(</rp><rt>音</rt><rp>)</rp></ruby>` 覆盖，**不改原文用字**（`assertSameOriginal` 逐字校验）。报告追加"复校"小节。

## 二、全面再扫清单（001–095 逐处对照上下文）

除已修过的类别外，本轮特别排查以下**易漏破读/异读**：

- **乘**：量词"辆"→shèng；乘坐/趁→chéng
- **度**：揣度/估量→duó；法度/限度→dù
- **遗**：赠送/馈赠→wèi；遗留→yí
- **强**：勉强/竭力→qiǎng；强大→qiáng
- **说**：游说→shuì；喜悦(通悦)→yuè；言说→shuō（如"孰能说之"按语境定）
- **中**：射中/符合/中选→zhòng；中间→zhōng
- **冠**：行冠礼(动词)→guàn；帽子(名词)→guān
- **胜**：能承受/尽→shēng（不胜、胜任）；胜利→shèng
- **禁**：禁得住→jīn；禁止→jìn
- **创**：创伤→chuāng；开创→chuàng
- 以及前轮清单：食sì/衣yì/语yù/雨yù/王wàng/数shuò、说→悦yuè/见→现xiàn/知→智zhì/女→汝rǔ/邪→耶yé/不→否fǒu、召shào/知氏zhì、夫fú/与欤yú、朝=早晨zhāo

## 三、不确定时（重要，同前）

文言读音多有争议，**宁可标注待核也不要猜**：能依通行中学教材/《古汉语常用字字典》《王力古汉语字典》确定的直接改；拿不准的**不改动**，登记到 `docs/pinyin-校正报告.md` "复校存疑"里交老师复核；**严禁臆造生僻读音**。

## 四、流程与验收

1. **分批**（如一次一阶段或每 10 篇）在 raw 加 `<ruby>` 覆盖；只动 ruby、不改汉字标点。
2. 在 `docs/pinyin-校正报告.md` 新增 **"## 复校（001–095，第二轮）"** 小节，逐处记录 `文件：词 — 字 — 旧音→新音 — 依据`，存疑单列。
3. 每批 `npm run build`（build:data + validate-data + validate-curriculum）**全绿**；`git commit`（如 `fix(pinyin): 复校 乘/度/遗/强 (二轮)`）。
4. 自查脚本（列出高危字在 001–095 的当前注音与上下文，人工扫读）：
```js
const fs=require("fs"),path=require("path");
const dir=path.resolve(__dirname,"../data/articles");
const watch=["乘","度","遗","强","说","中","冠","胜","禁","创","食","衣","语","雨","王","数","见","知","女","邪","不","召","夫","与","朝","属"];
for(const f of fs.readdirSync(dir).filter(x=>/^\d{3}\.json$/.test(x))){
  const id=f.slice(0,3); if(id<"001"||id>"095")continue;
  const d=JSON.parse(fs.readFileSync(path.join(dir,f),"utf8"));
  const plain=d.fullTextPlain;
  d.rubyAnnotations.forEach(r=>{ if(watch.includes(r.char)){
    const ctx=plain.slice(Math.max(0,r.pos-4),r.pos+4).replace(/\n/g,"");
    console.log(`${d.id} ${r.char}→${r.pinyin}  …${ctx}…`);
  }});
}
```
