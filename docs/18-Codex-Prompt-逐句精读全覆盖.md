# Codex Prompt · 逐句精读全文覆盖返修 + 覆盖率门禁

> 问题：部分文章的「逐句精读」只摘引了几句原文，大段句子没有逐句注释/翻译（如 001 曹刿论战只覆盖全文 14%）。目标：**让所有文章的逐句精读覆盖全文**，并新增校验门禁防止再犯。
>
> 机制：逐句精读来自 `content/samples/*.md` 的 `## 逐句精读` 段，被 `scripts/build-data.js` 的 `parseSections()` 解析为 `sections[]`（每段含 `original/annotations/translation`）。本次**只重写受影响文章的 `## 逐句精读` 这一段**（连同其分段注释/翻译），**不动**原文底本 `content/raw/*`、`## 原文`、`## 全文翻译` 及其它模块。

## 二、重写要求（逐句精读全覆盖）

- 把该文**全部原文**按意义单位切成若干段（`### 第N段`），使各段 `> 原文` 顺次拼接后**完整覆盖全文、无遗漏、保持原顺序**。
- 每段结构照 `docs/05` 模板：
  ```
  ### 第一段
  > {这一段的原文，逐字取自原文，含标点}
  **注释**：
  - **{词}**：{解释}   （讲这一段里的重点/难词、古今异义、一词多义）
  **翻译**：{这一段的白话翻译}
  **古今联系**：{可选，1–2点}
  ```
- 分段粒度：一般每段 1–3 句/一个意义单位；★★ 篇约 4–8 段，长篇（如 013、750 字级）更多。对话体（曹刿、邹忌、唐雎、触龙等）按"一问一答"或"一层意思"分段。
- `> 原文` 必须是原文的**逐字片段**（含标点），不得改字、不得用省略号跳过；把原来漏掉的句子补进相应段落。
- 每段的翻译要对应该段原文；可与 `## 全文翻译` 呼应但需分段落到位。

## 三、新增校验门禁（防止再犯，作用于全部文章）

在 `scripts/validate-data.js` 增加对每篇 `sections` 的检查，任一不过即 `process.exit(1)`：

1. **覆盖率**：`Σ(去空白后 section.original 长度) / 去空白后 fullTextPlain 长度 ≥ 0.90`。低于则报错并打印该篇 id 与实际覆盖率。
2. **顺序且不重叠**：各 `section.original`（去空白）都是 `fullTextPlain`（去空白）的子串，且在原文中的起始位置**严格递增**、区间不重叠（保证是顺次覆盖而非乱摘/重复）。
3. **分段下限**：`fullTextPlain` 去空白长度 > 200 时，`sections.length ≥ 2`（杜绝长文塞成一段）。

> 说明：现有已全覆盖的 023–050 等应能直接通过（阈值 0.90 留出标点/空白的余量）；A、B 两类返修后也须通过。

## 四、工作流程与验收

1. **分批返修**（如一次 3–4 篇）：只改这些篇的 `content/samples/*.md` 的 `## 逐句精读` 段。
2. 先加第三节的校验逻辑，再重写 A、B 两类文章；`npm run build`（build:data + validate-data + validate-curriculum）**全绿**。
3. 分批 `git commit`（如 `fix(sections): full-text 逐句精读 coverage for 001,006,015`）。
4. 验收：
   - 运行下方脚本，**全部 50 篇覆盖率 ≥ 90%**、无单段长文：
     ```bash
     node -e '
     const fs=require("fs"),p=require("path"),d=p.resolve("data/articles");
     const S=s=>String(s||"").replace(/\s/g,"");
     for(const f of fs.readdirSync(d).filter(x=>/^\d{3}\.json$/.test(x))){
       const a=JSON.parse(fs.readFileSync(p.join(d,f),"utf8"));
       const full=S(a.fullTextPlain).length||1;
       const cov=(a.sections||[]).reduce((s,x)=>s+S(x.original).length,0)/full;
       if(cov<0.9||((a.sections||[]).length<2&&full>200))
         console.log(a.id,a.title,Math.round(cov*100)+"%","段"+(a.sections||[]).length);
     }
     console.log("（无输出＝全部达标）");'
     ```
   - `npm run build` 全绿；`data/`、`content/raw/`、各篇 `## 原文`/`## 全文翻译` 未被改动。
