# Codex Prompt · 受众从「小学四年级」改为「中小学生」

> 目标：把产品定位从"面向小学四年级"扩展为**面向中小学生（小学到高中）**。这只是**受众表述/定位**的调整——**文章内容、难度分级、排课都不改**（现有 50 篇由易到难本就跨越各学段，"中小学生"反而比"四年级"更贴合）。

---

## 一、改动原则

- 把"小学四年级 / 四年级学生 / 小学生 / 9–10岁"等受众表述统一改为**"中小学生"**（必要处可写"小学到高中"或按学段分述）。
- 只改**表述与定位**，不改：`data/curriculum.json`、`data/articles/*`、`content/**` 里的原文/注释/翻译/题目/难度值。
- 改完后全库不应再有面向受众的"小学四年级/四年级"字样（历史归档的 prompt 文档 `docs/09–16` 可不动，见第四节）。

---

## 三、planning 文档（P1，保持定位一致）

在下列文档中把受众定位与年龄段改为中小学生，并对**明显只针对四年级**的说法做轻度改写（覆盖小学/初中/高中，不必大幅扩写）：
