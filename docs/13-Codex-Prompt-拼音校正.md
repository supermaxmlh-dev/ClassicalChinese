# Codex Prompt · 全文拼音校正（文言文破读/通假/专名/虚词）

> 背景：现在原文拼音由 `pinyin-pro` 在 `scripts/build-data.js` 的 `buildFullRubyAnnotations()` 中**逐字自动生成**，`content/raw/*.txt` 里的手工 `<ruby>` 会**按位置覆盖**自动结果（覆盖优先）。自动注音在常见字上基本正确，但在**文言文破读、通假字、专名异读、文言虚词**上系统性读错，而"显示全部拼音"会把错音直接展示给小学生。
>
> 目标：对 `content/raw/` 下**全部 50 篇**（001–050）校正这些读音，方式是在 raw 底本里给**需要纠正的那个字**加 `<ruby>` 手工注音。原文内容不变（构建比对的是去掉 ruby 后的纯文本，加 ruby 安全）。

---

## 一、机制与约束（先读懂）

- 修法：把 raw 中**读错的那一处**的字包成
  `<ruby>字<rp>(</rp><rt>正确拼音</rt><rp>)</rp></ruby>`，重建后该位置即用手工音。
- **只包需要纠正的字**：自动音正确的字不要动（如 为/相/见/数/长 等多音字 pinyin-pro 多数已正确消歧）。逐处按上下文判断，不是把某个字全篇统一替换。
- **不改动原文用字**：只加 ruby 包裹，不增删改任何汉字与标点。`assertSameOriginal` 会逐字校验，改错会构建失败。
- 拼音用**带声调符号**形式（如 `sì`、`zhāo`、`yú`），与现有 ruby 一致。

## 三、文言常见易错读音排查清单（逐篇对照上下文）

> 规则：只有当字在该句中取**下列文言义**时才纠正；取普通义时保持自动音。判断不准时按第四节处理，**不要臆造**。

**破读（依词义变调/变音）**
- 食：喂养→**sì**（食马者）；吃→shí
- 王：称王/统治→**wàng**（王天下）；君王→wáng
- 衣：穿→**yì**（衣褐）；衣服→yī
- 雨：降下→**yù**（雨雪）；雨水→yǔ
- 语：告诉→**yù**（语之曰）；言语→yǔ
- 远/近：以…为远→**yuàn/jìn**（动词用法，视文）
- 妻：嫁给→**qì**；妻子→qī
- 饮：使…喝→**yìn**（饮马）；喝→yǐn
- 重：重叠/再→**chóng**；分量重→zhòng
- 数：屡次→**shuò**；数目→shù；点数→shǔ
- 骑：骑兵/坐骑→**jì**（名词，视文）；骑→qí
- 创：创伤→**chuāng**；开创→chuàng

**通假（读本字音）**
- 说→悦 **yuè**；见→现 **xiàn**；知→智 **zhì**
- 女→汝 **rǔ**；邪→耶 **yé**；不→否 **fǒu**
- 反→返 fǎn；距→拒 jù；田→畋 tián；内→纳 nà
- 信→伸 shēn（视文）；从→纵 zòng（合从）

**专名/异读**
- 召公 **shào**；知罃/知氏 **zhì**；郤/卻 xì；阏 yān
- 仆射 yè；可汗 kèhán；月氏 ròuzhī（如涉及）

**文言虚词**
- 夫（发语词）**fú**；邪/与（疑问/感叹语气，=耶/欤）**yé / yú**
- 不（句末疑问，=否）**fǒu**

## 四、不确定时怎么办（重要）

文言读音多有争议，**宁可标注待核也不要猜**：
- 能依据通行中学教材/《古汉语常用字字典》《王力古汉语字典》确定的，直接改。
- 拿不准的，**不要改动**，而是登记到报告里（见第五节）交人工（老师）复核。
- 严禁为"看起来更像文言"而臆造生僻读音。

## 五、产出与工作流程

1. **逐篇处理**（一次一篇或一周四篇），在 `content/raw/{id}-*.txt` 加 `<ruby>` 覆盖。
2. 每篇生成/追加到 `docs/pinyin-校正报告.md`，记录：
   - 本篇**已改**的每一处：`位置/词 — 字 — 旧音→新音 — 依据`；
   - 本篇**存疑待核**的每一处：`词 — 字 — 候选读音 — 疑点`。
3. 跑 `npm run build` 必须**全绿**（`assertSameOriginal` 不报错说明只动了 ruby）。
4. 重新运行下方**校验脚本**自查，确认第二节已确认错误全部修正。
5. 分批 `git commit`（如 `fix(pinyin): correct 文言 readings for week 1-2`）。

**校验脚本**（可临时存为 `scripts/scan-pinyin.js`，列出指定字在全部文章中的当前注音与上下文，便于人工扫读）：
```js
const fs = require("fs");
const path = require("path");
const dir = path.resolve(__dirname, "../data/articles");
const watch = ["食","王","衣","雨","语","重","数","骑","说","见","知","女","邪","不","召","与","夫","恶","创","妻","饮"];
for (const file of fs.readdirSync(dir).filter(f => /^\d{3}\.json$/.test(f))) {
  const d = JSON.parse(fs.readFileSync(path.join(dir, file), "utf8"));
  const plain = d.fullTextPlain;
  const m = new Map(d.rubyAnnotations.map(r => [r.pos, r]));
  d.rubyAnnotations.forEach(r => {
    if (watch.includes(r.char)) {
      const ctx = plain.slice(Math.max(0, r.pos - 3), r.pos + 4).replace(/\n/g, "");
      console.log(`${d.id} ${r.char}→${r.pinyin}  …${ctx}…`);
    }
  });
}
```
