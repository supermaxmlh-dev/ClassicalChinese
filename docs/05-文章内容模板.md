# 文章内容模板规范

> 每篇文章的学习内容按以下标准模板制作，确保内容一致性和教学质量。

## 一、模板结构总览

每篇文章的内容文件命名格式：`{序号}-{篇名}.md`
例如：`001-曹刿论战.md`

完整模板包含以下模块：

```
1. 基础信息
2. 故事导读
3. 原文（含关键字拼音标注）
4. 逐句注释与翻译
5. 全文翻译
6. 文化拓展（延伸阅读）
7. 思考问题
8. 阅读理解练习题
9. 本篇重点词汇卡
10. 朗读节奏标注
```

## 二、各模块详细规范

### 模块1：基础信息

```markdown
---
id: 001
title: "曹刿论战"
source: "左传·庄公十年"
author: "左丘明"
dynasty: "春秋"
difficulty: 1
week: 1
word_count: 250
tags: ["左传", "军事", "谋略", "春秋"]
related_idioms: ["一鼓作气", "再衰三竭"]
---
```

字段说明：
- `id`: 全局唯一编号，001-222
- `difficulty`: 难度等级，1-5对应★-★★★★★
- `week`: 安排在第几周学习
- `tags`: 分类标签，用于网站筛选
- `related_idioms`: 相关成语

### 模块2：故事导读

用2-4句通俗易懂的白话文讲述文章大意，语气生动活泼，像在给孩子讲故事。

```markdown
## 故事导读

春秋时期，强大的齐国出兵攻打弱小的鲁国。鲁国有个叫曹刿的普通人，主动找到国君鲁庄公，要求一起上战场。在战场上，曹刿不让国君着急进攻，而是等齐军擂了三次鼓之后才下令冲锋——结果鲁国以少胜多，大获全胜！战后曹刿解释了自己的策略，成了千古名言。
```

**要求**：
- 字数：80-150字
- 语言：口语化，可适当使用感叹号增加趣味
- 内容：交代时间、人物、事件、结果
- 不要剧透所有细节，留有悬念引导阅读原文

### 模块3：原文（含拼音标注）

对生僻字和易读错的字标注拼音。使用ruby标注格式（HTML渲染时使用`<ruby>`标签）。

```markdown
## 原文

十年春，齐师伐我。公将战，曹<ruby>刿<rp>(</rp><rt>guì</rt><rp>)</rp></ruby>请见。其乡人曰："肉食者谋之，又何间<ruby>焉<rp>(</rp><rt>yān</rt><rp>)</rp></ruby>？"刿曰："肉食者<ruby>鄙<rp>(</rp><rt>bǐ</rt><rp>)</rp></ruby>，未能远谋。"乃入见。
```

**拼音标注原则**：
- 生僻字必标：如人名、地名中的罕用字
- 多音字在此处读音与常见读音不同时标注
- 通假字标注本字读音
- 古今读音有显著差异的字标注
- 每篇标注数量控制在5-15个字

### 模块4：逐句注释与翻译

将原文拆分为若干意义段落，每段给出注释和翻译。

```markdown
## 逐句精读

### 第一段

> 十年春，齐师伐我。公将战，曹刿请见。

**注释**：
- **十年**：鲁庄公十年（公元前684年）
- **齐师**：齐国的军队。师，军队
- **伐**：攻打（古今同义，但古文中更常见）
- **我**：指鲁国（《左传》以鲁国的视角记事）
- **公**：鲁庄公
- **请见**：请求拜见

**翻译**：鲁庄公十年的春天，齐国军队攻打鲁国。鲁庄公准备迎战，曹刿请求拜见他。

**古今联系**：
- "师"在古文中常指军队，现代汉语中保留了"出师""班师回朝"等说法
- "伐"表示大规模军事进攻，成语"口诛笔伐"中的"伐"引申为讨伐、声讨
```

**要求**：
- 注释重点突出古今异义词、一词多义、通假字
- 翻译通顺自然，不必逐字死译
- "古今联系"板块列出1-2个与现代汉语的关联点

### 模块5：全文翻译

完整的白话文翻译，语句通顺连贯。

```markdown
## 全文翻译

鲁庄公十年的春天，齐国军队攻打鲁国。鲁庄公准备迎战，曹刿请求拜见他。他的同乡说："那些吃肉的大官会谋划这件事，你又何必参与呢？"曹刿说："那些吃肉的大官目光短浅，不能深谋远虑。"于是入朝拜见鲁庄公。
……
```

### 模块6：文化拓展（延伸阅读）

```markdown
## 延伸阅读

### 关于作者
左丘明是春秋时期鲁国的史官……（100-150字）

### 历史背景
这场战争发生在公元前684年……（100-150字）

### 你知道吗？
- **一鼓作气**这个成语就出自这篇文章！……
- 古代打仗为什么要擂鼓？原来……

### 相关故事
（一段200-300字的相关历史故事或趣闻）
```

**要求**：
- 总字数200-400字
- 语言通俗有趣，像在讲故事
- 至少包含一个"你知道吗"类的趣味知识点
- 如有相关成语，详细解释其来源

### 模块7：思考问题

```markdown
## 想一想

1. 曹刿只是一个普通老百姓，为什么他敢去找国君谈打仗的事？你觉得他是一个怎样的人？

2. 曹刿的同乡劝他不要管，说"肉食者谋之"。如果你是曹刿，你会怎么选择？为什么？

3. 在生活中，你有没有遇到过需要等待最好时机才行动的事情？请举一个例子。
```

**要求**：
- 每篇2-3个思考题
- 至少1题联系学生的生活实际
- 开放性问题为主，不设标准答案
- 语言亲切，用"你"直接与学生对话
- 难度适中，中小学生能够思考和表达

### 模块8：阅读理解练习题

```markdown
## 小试牛刀

### 一、选择题

1. "肉食者鄙"中的"鄙"是什么意思？
   - A. 鄙视
   - B. 目光短浅 ✓
   - C. 卑鄙
   - D. 边远的地方

2. 曹刿认为能打胜仗的关键是什么？
   - A. 士兵数量多
   - B. 武器好
   - C. 取信于民 ✓
   - D. 地形有利

### 二、填空题

3. 写出下列加点字的意思：
   - 齐师**伐**我 → ______（攻打）
   - 又何**间**焉 → ______（参与）
   - **忠**之属也 → ______（尽力做好本分的事）

### 三、简答题

4. 用自己的话说说"一鼓作气，再而衰，三而竭"是什么意思。

### 四、挑战题（选做）

5. 请你当一回小翻译官，试着把下面这段原文翻译成白话文：
   "既克，公问其故。对曰：'夫战，勇气也。'"
```

**要求**：
- 选择题2-3道（考查字词理解和内容把握）
- 填空题1-2道（考查重点字词）
- 简答题1道（考查整体理解）
- 挑战题1道（选做，用于学有余力的学生）
- 每题附答案（答案在文件末尾统一给出，网站展示时默认隐藏）
- 题目难度：约70%学生能独立完成

### 模块9：本篇重点词汇卡

```markdown
## 词汇积累

| 词 | 古义 | 今义 | 例句 | 相关成语 |
|----|------|------|------|----------|
| 师 | 军队 | 老师 | 齐师伐我 | 出师不利 |
| 鄙 | 目光短浅 | 卑鄙 | 肉食者鄙 | 卑鄙无耻 |
| 间 | 参与 | 中间 | 又何间焉 | 间不容发 |
| 伐 | 攻打 | 砍伐 | 齐师伐我 | 口诛笔伐 |
| 克 | 战胜 | 克服 | 既克 | 攻无不克 |
```

**要求**：
- 每篇提取5-10个重点词汇
- 优先选取古今异义词和高频文言词
- 标注至少一个相关成语帮助记忆

### 模块10：朗读节奏标注

```markdown
## 朗读指导

十年春，齐师/伐我。公/将战，曹刿/请见。其乡人/曰："肉食者/谋之，又/何间焉？"刿曰："肉食者/鄙，未能/远谋。"乃/入见。
```

**要求**：
- 用"/"标注朗读停顿
- 标注原则：主语与谓语之间、动词与宾语之间、较长修饰语之后
- 参考语文教学规范

## 三、答案格式

所有练习题的答案统一放在文件末尾：

```markdown
## 参考答案

1. B
2. C
3. 伐：攻打；间：参与；忠：尽力做好本分的事
4. 示例答案：第一次擂鼓时，士气最旺盛；第二次擂鼓，士气就减弱了；第三次擂鼓，士气就耗尽了。比喻做事要一口气完成，不能拖延。
5. 已经战胜了齐军，鲁庄公问曹刿取胜的原因。曹刿回答说："打仗，靠的是勇气。"
```

## 四、配图要求

每篇文章配1-2张图片：

1. **主图**：体现文章核心场景或人物（命名：`{id}-main.jpg`）
   - 尺寸：800×500px
   - 风格：中国风水墨画或工笔风格
   - 内容：文章中最有画面感的场景

2. **人物图**（可选）：作者或文中主要人物（命名：`{id}-author.jpg`）
   - 尺寸：400×400px
   - 风格：简洁的人物画像

## 六、难度自适应标注

根据文章难度等级，内容模板有以下差异化处理：

| 模块 | ★ 启蒙级 | ★★-★★★ 中级 | ★★★★-★★★★★ 高级 |
|------|---------|-------------|------------------|
| 故事导读 | 详细（150字） | 适中（100字） | 简要（80字） |
| 注释密度 | 每句都注 | 重点句注释 | 仅难点注释 |
| 翻译方式 | 逐句展示 | 分段展示 | 全文展示 |
| 思考题数量 | 2题 | 3题 | 3题 |
| 练习题数量 | 4-5题 | 5-6题 | 6-7题 |
| 朗读标注 | 详细标注 | 关键处标注 | 仅长句标注 |
