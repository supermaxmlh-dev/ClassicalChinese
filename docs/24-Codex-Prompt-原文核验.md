# Codex Prompt · 原文核验（篇目归属 + 逐字比对权威全文）

> 背景：现有 95 篇（001–095）原文均由 AI 依 prompt 誊写，**未与权威版本比对过**；且疑似有若干篇**并不属于《古文观止》**。本次做两件事：(A) 判定每篇是否为《古文观止》篇目；(B) 对原文逐字比对权威全文，列出差异。**本轮只产出核验报告，不擅自改动内容**——发现的问题先汇总给我，我确认处置方式后再单独修。

## 一、权威来源（多源交叉，标注出处）

对每篇至少查 **2 个可信来源** 交叉核对，优先：
- 《古文观止》全文站：如 `gwgz.5000yan.com`、古诗文网 `gushiwen.cn`、维基文库 `zh.wikisource.org/wiki/古文觀止`；
- 单篇原文：古诗文网、维基文库对应作者/篇目页。

若两源本身有异文（版本差异），**记录异文并注明版本**，不擅自判定对错。

## 三、第二步：原文逐字比对（仅对 `in-guanzhi` 与 `uncertain` 的篇）

把 `content/raw/{id}-*.txt` 的**纯原文**（去掉 `<ruby>` 拼音后的汉字与标点）与权威全文逐字比对，列出：
- **缺字/衍字/错字/异体字**（如前例「知罃」曾误作异体）；
- **标点差异**（可与用字差异分开标注，标点从宽）；
- **段落/句子缺漏**。
每处差异记录：`篇id — 位置/上下文 — 现文 — 权威文 — 来源`。**不在本轮改动原文**。

## 五、约束与流程

- **只读核验、产出报告，不改 `content/`、`data/`、脚本**（除非我另行指示）。
- 分批做（如每 10–15 篇一批），每批把该批结论追加进报告并同步给我。
- 来源不可达/两源冲突且无法判定的，标 `uncertain` 并说明，**不猜**。
- 【网络限制】若某原文站无法访问，换用允许访问的可信站；仍不可得则标"来源待补"，不要以记忆代替核对。

完成每批请输出：本批各篇归属结论、发现的原文差异条目数、以及仍需人工定夺的存疑项。等我确认再继续下一批与后续处置（改定位 / 移除替换 / 订正原文）。
