# Codex Prompt · 填空题支持多答案（同义词均判对）

> 目标：把填空题的"唯一答案"改成**可接受答案数组**，学生填入其中任一同义说法都判对。例如「歇」的答案可同时接受 `消散 / 散去 / 消失`。
>
> 说明：静态站点没有词库，无法在运行时判断任意同义词，所以采用**作者预先列出同义答案**的方式——判分接受数组中任一项。改造涉及：构建解析、数据字段、判分逻辑、校验脚本，以及为现有 50 篇补同义答案。

---

## 一、现状（改造前）

- 数据：`data/articles/*.json` 每个填空为 `{ id, stem, targetChar, targetIndex, blank, hint }`，`blank` 是**单个字符串**。
- 来源：`content/samples/*.md`「## 参考答案」第 4 题形如 `军：驻军；厌：满足；去：离开`，由 `scripts/build-data.js` 的 `parseFillBlanks()` 按加点字映射成 `blank`。
- 判分：`js/quiz.js` 用 `input.value.trim() === question.blank.trim()` 精确匹配，错时显示 `正确答案：{blank}`。
- 校验：`scripts/validate-data.js` 检查 `fill.blank` 非空且非"略"。

---

## 二、改造要求

### 1) 作者书写约定（Markdown）
「## 参考答案」第 4 题里，一个加点字的多个可接受答案用**半角斜杠 `/`** 分隔，第一个为标准答案：
```
4. 军：驻军/进军；厌：满足/满足够了；去：离开/离去
```
- 分隔符只认 `/`（和全角 `／`）。不要用 `、`（可能出现在答案内部）。
- 仍是 `字：答案` 结构，多个字之间仍用 `；` 分隔。

### 2) 数据字段（build-data.js `parseFillBlanks`）
- 把某加点字的答案值按 `/`（含 `／`）拆分、去空白、去重，生成数组 **`answers: string[]`**（至少 1 项，`answers[0]` 为标准答案）。
- 兼容保留 `blank: answers[0]`（供旧读取/展示回退用）。
- 任一 `answers` 项为空或等于"略"→ `throw`（保持"不静默兜底"原则）。
- 其余字段（stem/targetChar/targetIndex）逻辑不变。

### 3) 判分（js/quiz.js 填空分支）
- 读取 `question.answers`（若无则回退 `[question.blank]`）。
- 归一化后比较：`input` 与每个候选都做 **trim + 去首尾空白 + 全角转半角 + 英文小写**（拼音填空用）后，**命中任一即判对**。
- 不要做过度归一化（如删标点、去"的"），以免把错误答案也放过。
- 判对反馈"填对了！"；判错反馈：`正确答案：{answers[0]}` + 若有备选则追加 `（也可：{answers.slice(1).join("、")}）`。

### 4) 校验（scripts/validate-data.js 填空段）
- 把对 `fill.blank` 的检查改为对 **`fill.answers`**：必须是**非空数组**、每项非空且不等于"略"、无重复。
- 保留 stem/targetChar/targetIndex/stem 在原文中 等现有校验。

---

## 三、为现有 50 篇补同义答案（内容）

- 遍历现有全部填空，在其「## 参考答案」第 4 题里，**给能自然接受多种说法的加点字补 1–2 个常见同义答案**（标准答案放第一位）。
- 只补**确属同义/等价**的说法；**专有、精确释义不要硬凑**（如「军=驻军」补「进军/驻扎」可，凑「军队」不可，因为此处是动词义）。
- 拿不准的保持单答案即可，不要臆造。
- 面向小学四年级：同义答案应是孩子会自然写出的等价表达（如 消散/散去、离开/离去、洗/洗涤、都/全）。

---

## 四、工作流程与验收

1. 先改 3 个脚本/前端（build-data、quiz、validate），用现有单答案数据重建，确认**全部变成 1 元素 `answers` 数组、判分与显示正常**、`npm run build` 全绿。
2. 再分批为 50 篇补同义答案，每批 `npm run build` 全绿后 `git commit`。
3. 验收：
   - 任取一题，填标准答案→判对；填其列出的同义词→**也判对**；填无关词→判错并显示 `正确答案：… （也可：…）`。
   - `data/articles/*.json` 中填空均含非空 `answers` 数组，无"略"。
   - `npm run build`（build:data + validate-data + validate-curriculum）全绿。
   - 得分统计（`computeScore`）在多答案下仍正确计入。
