# Codex Prompt · 翻译返修（全文翻译 + 逐句精读段翻译）

> 严重问题：大量"翻译"是**套话占位**，没有真正翻译。
> - **全文翻译**：70 篇是占位（形如"本文大意是：围绕"X"这一事件，作者写出人物在具体处境中……"）。仅 25 篇真实：`001–022、056、083、094`。
> - **逐句精读段翻译**：179 段占位（形如"这一段承接《X》…展开。阅读时要先分清人物…"／"这一段/层…围绕…"），涉及 54 篇。
>
> 目标：把这些占位替换为**真实、忠实、面向中小学生的白话翻译**。改的是 `content/samples/*.md`（`## 全文翻译` 段 与 `## 逐句精读` 各段的 `**翻译**：` 行）；`data/` 为生成物，改完重建。

## 一、准确性优先（务必遵守，降低臆造风险）

- **对照权威白话译文**：每篇优先参考古诗文网 `gushiwen.cn`、`gwgz.5000yan.com` 等的通行译文，再用**浅白、面向中小学生**的话复述；**不得逐字照抄权威译文的独特措辞**，但**信息要与之一致**。
- **忠实完整**：全文翻译要覆盖全篇每句；逐段翻译只译**该段 `> 原文`** 的内容，逐句落实，不遗漏、不添意。
- **拿不准就登记待核**：文言有歧义、异文或典故不清处，按通行注本译；仍不确定的**列入报告 `docs/翻译返修报告.md` 的"存疑"清单**，交人工复核，**不要臆造**。

## 三、写作要求

- 白话通顺、语气自然，适合中小学生；专有名词（人名/地名/官职）保留并可加一两字说明。
- **禁止**再出现："本文大意是""这一段承接""在全文中的作用""阅读时要先分清""围绕"…"展开""这一层/这一段…围绕"等空泛表述，以及把文言原文整段塞进"翻译"里充数。
- 逐段翻译与全文翻译**内容一致**（不能自相矛盾）。

## 四、防复发校验（新增，构建失败即拦）

在 `scripts/validate-data.js`（对 `fullTranslation` 与 `sections[].translation`）增加：
1. **占位黑名单**：命中"本文大意是"、"这一段承接"、"在全文中的作用"、"阅读时要"+"分清"、"围绕"+"展开"、以`这一层/这一段/本段`开头且含"围绕/大意"等 → 报错。
2. **原文照抄检测**：翻译中若出现该段/全文 `原文` 里**连续 ≥ 12 个汉字**的原样片段 → 报错（真白话不会大段照抄文言）。
3. **过短检测**：`fullTranslation` 汉字数 < 该篇 `fullTextPlain` 的 40% → 报错（疑似没译全）；段翻译不得为空。

## 五、流程与验收

1. **严格按第二节的 12 个批次顺序做，一次一批**（第 1 批 → 第 12 批），只改该批列出篇目对应的 `content/samples/*.md`。
2. 每批 `npm run build`（build:data + build:dictionary + validate-*）**全绿**；把该批的"已改/存疑"追加进 `docs/翻译返修报告.md`，并在报告顶部维护一个「进度：已完成 X/12 批」。
3. 自查脚本（占位应清零）：
   ```bash
   node -e '
   const fs=require("fs"),p=require("path"),d=p.resolve("data/articles");
   const PH=["本文大意是","这一段承接","在全文中的作用","阅读时要","围绕“"];
   let full=0,seg=0;
   for(const f of fs.readdirSync(d).filter(x=>/^\\d{3}\\.json$/.test(x))){
     const a=JSON.parse(fs.readFileSync(p.join(d,f),"utf8"));
     const bad=t=>PH.some(x=>String(t||"").includes(x));
     if(bad(a.fullTranslation))full++;
     for(const s of a.sections||[])if(bad(s.translation))seg++;
   }
   console.log("占位全文翻译:",full,"| 占位段翻译:",seg);'
   ```
   期望：**两者都为 0**。
4. **抽查准确性**：随机取 5 篇（含 001 曹刿论战、006 邹忌、070 前赤壁赋），把全文翻译与权威译文对照，意思一致、无漏译、无硬伤。
5. 分批 `git commit`（如 `fix(translation): 真实白话翻译 023-030`）。

**每批完成请输出**：本批篇目、改了多少处全文/段翻译、`npm run build` 结果、自查脚本数字、以及"存疑待核"清单。等我确认再继续下一批。
