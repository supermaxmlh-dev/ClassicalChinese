# 观止学堂 — 网站设计需求文档

## 一、技术栈

- **前端**：纯静态 HTML/CSS/JavaScript（无框架依赖）
- **部署**：GitHub Pages 或任意静态托管
- **数据存储**：LocalStorage（学习进度）+ JSON 文件（课程内容）
- **无需后端**：所有内容预构建为静态文件

## 二、页面结构

### 2.1 页面清单

```
/
├── index.html              # 首页（学习地图）
├── week/{n}.html           # 每周学习页（52个）
├── article/{id}.html       # 文章详情页（222个）
├── vocab.html              # 词汇宝库
├── progress.html           # 学习进度
├── about.html              # 关于本站
└── review/{n}.html         # 阶段测评页（4个）
```

### 2.2 首页 — 学习地图

**功能描述**：
- 以时间轴或地图形式展示52周学习旅程
- 每周显示为一个"站点"，标注本周主题和篇目数
- 已完成的周标记为绿色，当前周高亮，未解锁的周灰显
- 四个阶段（启蒙/成长/提升/突破）以不同颜色区分
- 顶部显示总体进度条和已学篇数统计

**视觉风格**：
- 古风水墨画背景，卷轴感设计
- 配色：以暖色调为主（米黄/浅棕/墨绿/朱红）
- 字体：正文用宋体或楷体，标题可用书法字体
- 整体风格既有古韵又不失现代简洁感

### 2.4 文章详情页（核心页面）

**功能描述**：

**顶部区域**：
- 文章标题（大字）、来源、作者、朝代
- 难度星级显示
- 配图（JPG格式主图）

**故事导读区**：
- 默认展开，用浅色卡片突出显示
- 配以小图标增加趣味

**原文区**：
- 原文以大字显示，行间距适当加大
- 生僻字hover/点击显示拼音和释义
- 提供"显示节奏标注"开关（用"/"标注停顿）
- 提供"显示拼音"开关（全文拼音标注）

**注释与翻译区**：
- 逐句/逐段展示
- **翻译默认折叠**，点击"查看翻译"展开
- 注释以侧边悬浮/弹窗方式呈现
- "古今联系"用特殊样式标注

**延伸阅读区**：
- 折叠式展示，点击展开
- 包含作者介绍、历史背景、趣味知识

**练习区**：
- 思考题展示（开放性，无标准答案）
- 阅读理解题：交互式作答

  - 填空题：输入框提交后对比答案
  - 简答题：展示参考答案供自评
- 完成练习后显示得分和鼓励语

**底部导航**：
- 上一篇 / 下一篇
- 返回本周
- 标记为已完成

**功能描述**：

## 三、交互设计规范

### 3.1 核心交互

| 交互 | 描述 |
|------|------|
| 字词点击 | 原文中的生僻字点击/hover显示注释弹窗 |
| 翻译展开 | 翻译默认隐藏，点击按钮逐段展开 |
| 练习作答 | 选择题即时反馈，答对变绿+鼓励，答错变红+提示 |
| 进度保存 | 完成文章/测评自动保存到LocalStorage |
| 主题切换 | 支持亮色/暗色模式切换（保护视力） |

### 3.2 响应式设计

- **桌面端**（≥1024px）：双栏布局，侧边显示注释
- **平板端**（768-1023px）：单栏布局，注释弹窗
- **手机端**（<768px）：单栏布局，字号适当增大，注释底部弹出

### 3.3 字体规范

```css
/* 标题 */
font-family: "STKaiti", "楷体", "KaiTi", serif;

/* 原文正文 */
font-family: "STSong", "宋体", "SimSun", serif;
font-size: 1.25rem; /* 原文稍大 */
line-height: 2;     /* 行间距放大，方便阅读 */

/* 注释/翻译/正文 */
font-family: "PingFang SC", "Microsoft YaHei", sans-serif;
font-size: 1rem;
line-height: 1.8;
```

```json
    {
      "name": "启蒙期",
      "weeks": [1, 13],
      "color": "#4CAF50",
      "badge": "文言新秀"
    },
    ...
  ],
  "weeks": [
    {
      "week": 1,
      "theme": "初识古文之美",
      "articles": ["001", "002", "003", "004"],
      "focusWords": ["欲", "遂", "盖", "但"],
      "isReview": false
    },
    ...
  ]
}
```

### 4.2 文章数据 `data/articles/{id}.json`

按照模板规范中的JSON格式存储每篇文章的元数据。

### 4.3 进度数据（LocalStorage + 导出/导入）

**存储方式**：LocalStorage（主存储）+ JSON 文件导出/导入（备份与迁移）

```json
{
  "guanzhi_progress": {
    "version": 1,
    "studentName": "小明",
    "completedArticles": ["001", "002", "003"],
    "completedWeeks": [1],
    "quizScores": {
      "001": 85,
      "002": 90
    },
    "reviewPassed": [1],
    "badges": ["文言新秀"],
    "vocabLearned": 52,
    "lastVisit": "2026-09-15",
    "currentWeek": 12,
    "createdAt": "2026-09-01",
    "exportedAt": null
  }
}
```

**导出/导入功能规范**：

| 功能 | 说明 |
|------|------|
| 导出进度 | 将 LocalStorage 数据序列化为 `.json` 文件下载，文件名含学生姓名和日期（如 `小明-进度-2026-12-15.json`） |
| 导入进度 | 上传 `.json` 文件，校验数据格式和版本号后写入 LocalStorage，导入前弹窗确认（覆盖当前数据） |
| 自动提醒 | 每隔2周弹出提示"建议导出备份学习进度"，用户可选择导出或跳过 |
| 入口位置 | 进度页底部设"导出进度"和"导入进度"按钮；首次访问时也引导设置学生姓名 |

**数据校验规则**：
- 导入时检查 `version` 字段兼容性
- 检查 `completedArticles` 中的 id 是否合法（001-222）
- 导入成功后刷新页面以同步所有状态

## 五、性能要求

- 首页加载时间 < 3秒
- 文章页加载时间 < 2秒
- 所有图片使用懒加载
- 支持PWA离线缓存（可选，二期功能）
- 图片统一使用JPG格式，压缩至100KB以内

## 六、无障碍设计

- 原文字号≥18px，可调节
- 所有图片有alt描述
- 键盘可导航
- 颜色对比度满足WCAG AA标准
- 暗色模式支持

## 七、SEO与分享

- 每个文章页有独立的title和meta description
- 支持分享到微信/微博（生成卡片）
- 结构化数据标记（JSON-LD）
